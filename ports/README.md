# Ports Struktur

Dieses Verzeichnis enthält die Exports und Konfigurationen für die verschiedenen Zielanwendungen:

- `raycast/`: Raycast Pro Theme JSON & Deeplink Setup
- `ghostty/`: Ghostty Theme Config (`mystyle.conf`)
- `pi/`: Pi Coding Agent Custom Theme
- `vscode/`: Visual Studio Code Color Theme Extension / JSON
- `lazygit/`: Lazygit Theme Config (`config.yml` Snippet)
- `lazydocker/`: Lazydocker Theme Config (`config.yml` Snippet)
- `herdr/`: Herdr Theme Config
